## UGen300 技術主張界線

[ASUS 官方產品頁](https://www.asus.com/tw/motherboards-components/ai-accelerator/ugen/ugen300-usb-8g/)將 UGen300 定義為 Hailo-10H USB AI 加速器，需搭配相容主機。主機執行 Windows 狀態蒐集、使用者授權和維修動作。USB 儲存裝置負責攜帶程式／資料；UGen300 是另一個預計用於模型推論的裝置。

產品頁列出 Windows 支援，但也保留 Windows 驅動時程註記。這不能證明本專案已可使用特定 Windows 版本、HailoRT、模型與裝置組合。取得硬體後，須實測驅動、runtime、模型格式和斷線處理。本次完全沒有 UGen300 實測、加速效能或硬體維修成果。
